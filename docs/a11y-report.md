## 2026-11-11 편집 입력의 프로그램상 이름 (D15)

외부 재검수에서 axe 검사가 빈 화면·악보·공유·세션·반복 기호 경고 장면만 보아, 편집 패널의 입력·선택 상자에 이름이 없는 곳을 놓친다는 지적이 있었습니다. 같은 날 `tests/e2e/a11y/input-names.spec.js`가 악보를 연 상태에서 패널 21개를 차례로 열어(조건부로 나타나는 입력은 먼저 드러내고 최소 개수로 드러났는지도 확인) 보이는 `input`·`select`·`textarea`가 모두 연결된 `label` 글자, `aria-label`, `aria-labelledby` 중 하나를 갖는지 검사합니다. placeholder와 title은 이름으로 치지 않습니다.

고치기 전에는 16곳이 이름 없이 나왔습니다: 조옮김의 반음 수, 음역대의 악기 선택·사용자 지정 최저음·최고음, 이조 악기의 악기 선택·반음 차이, 템포 슬라이더, Ossia의 시작·끝 마디·조옮김·옥타브 이동·파트 이름, 내보내기의 파일 선택, 화성 쌓기의 대상 선택, 코드 변경 규칙의 원본·변경 입력. 문구가 이미 옆에 있던 곳은 `label`의 `htmlFor`와 입력의 `id`로 이었고, 문구가 없던 곳은 `aria-label`을 달았습니다. 글자 "✕"뿐이던 코드 규칙 삭제 단추도 `코드 변경 규칙 N 삭제` 이름을 받았습니다. 재생기의 조작 단추 이름도 함께 지키는 시험이 있습니다.

이 검사는 이름이 코드에 연결돼 있는지를 확인하는 것이고, 실제 스크린 리더(NVDA·VoiceOver 등)로 모든 패널을 읽어 본 결과는 아닙니다. 그 검증과 모바일 실기기 확인은 별도 점검으로 남아 있습니다.
