기준 버전Studio09 개선판
갱신일2026년 9월 3일
준비물MusicXML 또는 MXL 악보

01. 업로드하고 조옮기기

  1. MusicXML/MXL 파일을 업로드합니다. 여러 파일이면 상단 파일 탭으로 현재 악보를 선택합니다.
  2. 조옮김을 열고 목표 조 또는 반음 수를 지정합니다.
  3. 변환 실행을 누릅니다. 음표와 코드 기호가 함께 변했는지 확인합니다.
  4. 결과가 다르면 Ctrl+Z로 되돌립니다.
원본은 별도로 보관하세요. 화면 알림과 각 패널의 결과 로그를 확인하면 오류가 난 파일을 찾을 수 있습니다.

02. 분석과 보기 조절

  1. 오른쪽 코드 분석 또는 로마 숫자 분석을 열고 분석 버튼을 누릅니다.
  2. 필요하면 로마 숫자 분석의 악보에 삽입, 숫자 악보의 한국어 계이름을 실행합니다.
  3. 하단 ▶로 재생합니다. 처음에는 불러오는 시간이 필요하며 커서가 현재 마디를 표시합니다.
  4. 줌 버튼이나 Ctrl+＋/－로 확대·축소하고 맞춤으로 너비를 조절합니다.

모바일은 도구를 누르고 목록에서 기능을 선택합니다. 닫기로 악보 화면에 돌아옵니다.

03. 저장하고 다시 열기

원하는 결과누를 버튼
작업을 나중에 이어하기세션 → 이름 입력 → 저장
다른 브라우저로 작업 옮기기세션 → JSON 내보내기 / JSON 가져오기
다른 악보 프로그램으로 전달MXL (압축 MusicXML)
인쇄·문서에 붙이기PDF (브라우저 인쇄) / PNG / SVG
현재 악보 링크 전달공유 → URL 복사

파일 탭·현재 선택·Ossia는 세션과 함께 보관됩니다. 자동저장은 변경 후 약 5초 뒤 실행되며 별도의 JSON 백업도 권합니다.
