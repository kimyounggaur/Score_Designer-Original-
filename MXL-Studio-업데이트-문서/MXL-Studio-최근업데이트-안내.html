악보 편집·저장·재생·화면 흐름의 개선 안내

2026년 9월 3일

악보 편집과 저장

  • 음표를 바꾸면 공유 링크와 저장 파일에도 현재 편집 내용이 반영됩니다.
  • MXL은 표준 압축 MusicXML로 저장합니다. 비압축 XML 내보내기도 사용할 수 있습니다.
  • 조옮김은 코드 심볼·슬래시 베이스·단조·이조 악기를 반영하며 ♯/♭ 음이름 표기를 선택할 수 있습니다.
  • Ossia는 원래 마디 번호로 선택하고 세션·공유·자동저장에 함께 보관합니다.
  • 코드 심볼 33종, C/E, F#m7b5, Bbadd9, N.C.를 공통 파서로 처리합니다.

화면과 작업 흐름

  • 여러 파일을 올리면 파일 탭이 나타납니다. 현재 파일의 조성·파트·마디 정보를 표시합니다.
  • 좌우 패널 열기·닫기와 너비 조절, 악보 줌과 너비 맞춤을 지원합니다.
  • 세션 목록에서 이름을 붙여 저장하고 불러오기·삭제·이름 변경·JSON 내보내기·JSON 가져오기를 수행합니다.
  • 입력을 막는 팝업 대신 화면 알림과 패널별 오류 안내를 사용합니다.
  • 모바일은 도구 목록과 아래쪽 드로어, 공유·세션·내보내기 메뉴를 제공합니다.
  • PDF 버튼은 브라우저 인쇄 창을 열고 악보만 출력합니다.

재생과 분석

  • 붙임줄을 하나의 소리로 이어 재생하고 셈여림, 반복·1/2번 괄호, 마디 안 템포 변화를 반영합니다.
  • 커서와 마디 표시가 반복·A-B 구간을 따라 이동합니다. 못갖춘마디 0도 유지합니다.
  • 로마 숫자 분석은 단조 i-iv-V7-i, 전위 I6, 부속화음 V7/V를 표시합니다.
  • 숫자 악보에서 기존 가사를 복원할 수 있습니다.
  • D.C./D.S./Fine/코다 이동과 녹음된 악기 음색은 이번 재생 범위에 포함되지 않습니다.

속도와 안정성

  • 처음 여는 패널 수가 21개에서 2개로 줄었고 방문한 패널의 입력은 유지합니다.
  • 동일한 내용은 다시 자동저장하지 않으며 기록에는 XML 문자열 스냅샷을 사용합니다.
  • 재생 라이브러리는 첫 재생 클릭 시에만 내려받습니다.
  • 이 Windows 환경의 초기 화면 표시 3회 평균은 4.18초에서 2.17초로 감소했습니다. 네트워크와 기기에 따라 달라집니다.
  • 단위 테스트 84개, 전체 브라우저 테스트 80개가 통과했습니다. 접근성 검사 네 장면의 serious/critical 위반은 0입니다.

예정 기능

이전 안내에 있었던 주석 메모, 청음 훈련, 난이도 평가, 운지법 표시, QR 코드, 성부 진행·패턴 검색·형식 분석은 현재 제공 기능이 아닙니다. 설계 문서의 선택 Phase 9에서 별도로 다룹니다.

배포와 문서

사용자 설명서와 퀵스타트의 HTML·화면 캡처·PDF·SVG를 현재 기능에 맞춥니다. HTML이 정본입니다. GitHub Pages 배포와 테스트 워크플로는 준비되어 있으며 실제 배포는 저장소 푸시 후 실행합니다. 공개 주소는 저장소 변수 PROD_BASE_URL로 설정합니다. Linux 시각 회귀 기준 이미지 3장은 CI에서 생성·검토해야 합니다.
