최근 업데이트 안내

이번 업데이트는 작업을 더 안전하게 저장하고, 악보를 더 쉽게 공유하며, 핵심 기능을 자동으로 확인하는 안정성 개선에 초점을 맞췄습니다.

한눈에 보는 핵심 변화

사용자가 바로 체감할 변화는 자동 저장/세션 복원, 압축 공유 URL, 공유 링크 안내, 그리고 전체 앱 안정성 강화입니다.

1세션 복원 강화

브라우저를 다시 열어도 이전 작업을 복원하기 쉬워졌습니다.

2압축 공유 URL

악보를 더 짧은 링크와 QR 코드로 공유할 수 있습니다.

3자동 테스트

업로드, 조옮김, 공유 같은 핵심 흐름을 자동으로 확인합니다.

1. 자동 저장과 세션 복원이 더 안전해졌습니다

작업 중인 파일, 편집 기록, 세션 정보를 더 안정적인 저장 구조로 보관합니다. 실수로 창을 닫아도 이전 작업으로 돌아갈 가능성이 높아졌습니다.

  1. 악보를 업로드하고 편집합니다.
  2. 작업 중에는 자동 저장이 백그라운드에서 동작합니다.
  3. 브라우저를 다시 열면 이전 작업이 있을 때 복원 안내가 표시됩니다.
  4. 복원하기를 누르면 이전 세션으로 돌아갑니다.
  5. 중요 작업은 세션 버튼에서 별도로 저장하거나 JSON으로 내보냅니다.
추천 흐름: 파일 업로드 -> 세션 저장 -> 조옮김/분석/주석 추가 -> 결과 확인 -> JSON 백업 또는 PDF 내보내기

2. 공유 링크가 더 똑똑해졌습니다

상단 공유 버튼을 누르면 선택한 악보를 URL 안에 담아 공유할 수 있습니다. 새 방식은 데이터를 압축해 더 효율적인 링크를 만듭니다.

공유 URL은 단일 파일에 가장 적합합니다. 긴 곡이나 큰 편성 악보는 PDF, MXL, JSON 세션으로 공유하는 편이 안전합니다.

3. 기존 공유 링크도 계속 열 수 있습니다

새 압축 공유 방식이 들어왔지만 예전에 만든 링크도 계속 사용할 수 있습니다. 앱이 링크 형식을 자동으로 확인해 새 방식과 예전 방식을 모두 처리합니다.

4. 자동 테스트로 핵심 기능을 계속 확인합니다

사용자가 직접 보지는 않지만, 이번 업데이트에는 중요한 안정성 개선이 들어갔습니다.

자동 확인 항목의미
빈 앱 로드앱이 기본 상태에서 오류 없이 열리는지 확인합니다.
MusicXML 업로드파일 업로드와 악보 렌더링이 정상인지 확인합니다.
조옮김반음 이동 같은 핵심 편집이 정상 적용되는지 확인합니다.
자동 저장 복원새로고침 후 이전 작업을 복원할 수 있는지 확인합니다.
압축 공유 링크공유 링크를 새 페이지에서 열 수 있는지 확인합니다.

5. 최근 정리된 학습 도구 흐름

최근 버전에서는 청음 훈련, 코드 분석, 난이도 평가, 코드 없는 구간 처리 같은 학습 도구 흐름도 함께 개선되었습니다.

A청음 훈련/코드 분석 위치 정리

학습 도구를 더 자연스럽게 찾을 수 있게 정리되었습니다.

B난이도 평가 패널

악보의 학습 난이도를 파악해 수업 준비에 활용할 수 있습니다.

C세부 악보 처리 품질 개선

코드가 없는 구간 처리 등 작은 오류 가능성을 줄였습니다.

추천 사용 시나리오

수업용 악보를 빠르게 만들어 공유하기

  1. MusicXML 파일을 업로드합니다.
  2. 조옮김이 필요하면 왼쪽 조옮김 패널에서 변환합니다.
  3. 오른쪽 코드 분석 또는 로마 숫자 분석으로 해설 자료를 준비합니다.
  4. 주석 메모로 학생에게 보여 줄 설명을 추가합니다.
  5. 상단 공유 버튼으로 링크를 만들거나 PDF로 내보냅니다.

작업을 안전하게 이어 하기

  1. 큰 편집 전에 세션 버튼을 누릅니다.
  2. 현재 세션을 저장합니다.
  3. 필요하면 JSON으로 내보내 별도 보관합니다.
  4. 다음에 앱을 열었을 때 복원 안내가 나오면 복원하기를 선택합니다.
이번 업데이트를 한 문장으로 말하면, MXL Studio가 악보를 더 안전하게 저장하고, 더 쉽게 공유하고, 더 안정적으로 작동하도록 개선되었습니다.
