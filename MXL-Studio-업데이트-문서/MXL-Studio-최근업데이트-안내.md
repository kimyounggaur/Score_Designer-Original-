# MXL Studio 최근 업데이트 안내

작성일: 2026년 7월 6일  
대상: 악보 디자이너 웹앱을 사용하는 음악 교사, 편곡자, 수업 자료 제작자

## 한눈에 보는 핵심 변화

이번 업데이트의 중심은 **저장 안정성**, **공유 편의성**, **테스트 자동화**입니다.  
작업 중인 악보를 더 안전하게 보관하고, 학생이나 동료에게 더 쉽게 공유하며, 업데이트 후에도 주요 기능이 계속 정상 작동하는지 자동으로 확인하도록 개선했습니다.

| 새 기능 | 무엇이 좋아졌나요? | 어디서 쓰나요? |
|---|---|---|
| 자동 저장과 세션 복원 강화 | 브라우저를 닫았다가 다시 열어도 이전 작업을 복원하기 쉬워졌습니다. | 상단 **세션** 버튼, 이전 세션 복원 배너 |
| 압축 공유 URL v2 | 악보 데이터를 더 짧은 공유 링크로 만들고 QR 코드도 함께 제공합니다. | 상단 **공유** 버튼 |
| 공유 링크 크기 안내 | 원본 크기와 압축 후 크기를 보여 주고, 링크가 너무 크면 알려 줍니다. | 공유 창 |
| 예전 공유 링크 호환 | 기존 방식으로 만든 공유 링크도 계속 열 수 있습니다. | 공유 링크를 열 때 자동 처리 |
| 자동 회귀 테스트 | 업로드, 조옮김, 자동 저장, 공유 링크 같은 핵심 흐름을 자동 확인합니다. | 사용자에게는 더 안정적인 업데이트로 체감됩니다. |

## 1. 자동 저장과 세션 복원이 더 안전해졌습니다

이전에는 브라우저 저장 공간에 간단히 저장하는 방식이 중심이었다면, 이제는 더 안정적인 저장 구조를 사용합니다.  
작업 중인 파일, 편집 기록, 세션 정보를 더 튼튼하게 보관할 수 있게 되었습니다.

### 이렇게 사용하세요

1. 악보를 업로드하고 편집합니다.
2. 작업 중에는 자동 저장이 백그라운드에서 동작합니다.
3. 브라우저를 다시 열면 이전 작업이 있을 때 복원 안내가 표시됩니다.
4. **복원하기**를 누르면 이전 세션으로 돌아갑니다.
5. 중요한 작업은 상단 **세션** 버튼에서 별도로 저장하거나 JSON으로 내보내세요.

### 이런 점이 좋아졌습니다

- 실수로 창을 닫아도 작업을 이어 할 가능성이 높아졌습니다.
- 자동 저장과 수동 세션 저장을 함께 사용할 수 있습니다.
- 기존 저장 방식의 데이터도 새 저장 방식으로 옮겨 오도록 준비되어 있습니다.
- 저장된 세션 목록을 시간순으로 관리하기 쉬워졌습니다.

### 추천 사용법

수업 자료를 오래 편집할 때는 다음 순서가 좋습니다.

1. 파일 업로드
2. 큰 편집 전 **세션 저장**
3. 조옮김, 분석, 주석 추가
4. 결과 확인
5. JSON 백업 또는 PDF 내보내기

## 2. 공유 링크가 더 똑똑해졌습니다

상단 **공유** 버튼을 누르면 선택한 악보를 URL 안에 담아 공유할 수 있습니다.  
이번 업데이트에서는 공유 데이터가 압축되어 더 효율적인 링크로 만들어집니다.

### 공유 창에서 볼 수 있는 정보

- 공유 URL
- QR 코드
- 원본 데이터 크기
- 압축 후 데이터 크기
- 압축으로 줄어든 비율
- 링크가 너무 클 때의 경고 메시지

### 이렇게 사용하세요

1. 악보를 하나 업로드합니다.
2. 필요한 편집을 마칩니다.
3. 상단 **공유** 버튼을 누릅니다.
4. URL을 복사하거나 QR 코드를 사용합니다.
5. 받은 사람은 링크를 열어 같은 악보를 불러올 수 있습니다.

### 주의할 점

- 공유 URL은 **단일 파일** 공유에 가장 적합합니다.
- 긴 곡이나 큰 편성 악보는 링크가 길어질 수 있습니다.
- 링크가 너무 크다는 안내가 나오면 PDF, MXL, JSON 세션으로 공유하는 편이 안전합니다.
- QR 코드는 너무 긴 링크에서는 표시가 제한될 수 있습니다.

## 3. 기존 공유 링크도 계속 열 수 있습니다

새 압축 공유 방식이 들어왔지만, 예전에 만든 공유 링크를 버리지 않아도 됩니다.  
앱이 공유 링크 형식을 자동으로 확인해서 새 방식과 예전 방식을 모두 처리합니다.

### 사용자 입장에서 달라지는 점

- 예전 링크를 다시 만들 필요가 없습니다.
- 새 링크는 더 효율적으로 공유됩니다.
- 링크를 여는 사람은 별도 설정 없이 악보를 불러올 수 있습니다.

## 4. 공유 창이 더 친절해졌습니다

공유 창에는 이제 링크만 나오는 것이 아니라, 공유 가능한 상태를 더 쉽게 판단할 수 있는 정보가 함께 표시됩니다.

### 새로 보이는 안내

- `원본 2.2KB -> 압축 758B`
- `66% 절감`
- 링크가 큰 경우 경고
- QR로 표시하기 어려운 경우 안내

이 정보 덕분에 사용자는 “이 링크를 그대로 보내도 될지”, “PDF로 보내는 편이 나을지”를 더 쉽게 판단할 수 있습니다.

## 5. 자동 테스트로 핵심 기능을 계속 확인합니다

이번 업데이트에는 사용자가 직접 보지는 않지만 중요한 안정성 개선도 포함되었습니다.  
앱의 주요 기능이 업데이트 후에도 계속 동작하는지 자동으로 검사하는 테스트가 추가되었습니다.

### 자동으로 확인하는 대표 흐름

- 빈 앱이 오류 없이 열리는지
- MusicXML 파일이 정상 업로드되는지
- 악보 조옮김이 정상 적용되는지
- 자동 저장 후 새로고침해도 복원할 수 있는지
- 압축 공유 링크를 새 페이지에서 열 수 있는지

### 왜 중요한가요?

MXL Studio는 기능이 많은 도구입니다.  
한 기능을 고치다가 다른 기능이 갑자기 깨질 수 있기 때문에, 자동 테스트는 업데이트 품질을 지키는 안전망 역할을 합니다.

## 6. GitHub Pages 배포 흐름도 더 안정적으로 관리됩니다

웹앱은 정적 페이지로 배포되는 구조입니다.  
최근에는 배포 설정과 배포 후 확인 흐름도 정리되어, 공개 페이지에서 기본 기능이 정상 작동하는지 확인하기 쉬워졌습니다.

### 사용자에게 좋은 점

- 공개 링크에서 앱을 더 안정적으로 사용할 수 있습니다.
- 배포 후 핵심 기능을 점검하는 흐름이 준비되었습니다.
- 업데이트가 누적되어도 기본 사용 흐름을 지키기 쉬워졌습니다.

## 7. 최근 추가/정리된 학습 도구 흐름

최근 버전에는 기능 위치와 학습 도구 흐름도 함께 정리되었습니다.

### 사용자가 체감할 수 있는 변화

- 청음 훈련과 코드 분석 도구의 위치가 더 자연스럽게 정리되었습니다.
- 난이도 평가 패널을 통해 악보의 학습 난이도를 파악하기 쉬워졌습니다.
- 코드가 없는 구간 처리처럼 세부 악보 처리 품질도 개선되었습니다.

## 추천 사용 시나리오

### 수업용 악보를 빠르게 만들어 공유하기

1. MusicXML 파일을 업로드합니다.
2. 조옮김이 필요하면 왼쪽 **조옮김** 패널에서 변환합니다.
3. 오른쪽 **코드 분석** 또는 **로마 숫자 분석**으로 해설 자료를 준비합니다.
4. **주석 메모**로 학생에게 보여 줄 설명을 추가합니다.
5. 상단 **공유** 버튼으로 링크를 만들거나, **PDF**로 내보냅니다.

### 작업을 안전하게 이어 하기

1. 큰 편집 전에 **세션** 버튼을 누릅니다.
2. 현재 세션을 저장합니다.
3. 필요하면 JSON으로 내보내 별도 보관합니다.
4. 다음에 앱을 열었을 때 복원 안내가 나오면 **복원하기**를 선택합니다.

## 이번 업데이트를 한 문장으로 말하면

**MXL Studio가 악보를 더 안전하게 저장하고, 더 쉽게 공유하고, 업데이트 후에도 더 안정적으로 작동하도록 개선되었습니다.**
