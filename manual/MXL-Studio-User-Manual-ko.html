1. 앱 개요와 화면 구조

MXL Studio는 MusicXML 악보를 브라우저에서 바로 열어 수업용 자료로 바꾸는 웹앱입니다. 화면은 악보를 중앙에 놓고, 왼쪽에는 변환 도구, 오른쪽에는 분석과 보조 도구를 배치합니다.

기억할 점
중앙 악보는 결과를 확인하는 공간이고, 실제 조작은 좌우 인스펙터에서 이루어집니다. 상단 메뉴는 같은 기능을 이름으로 찾는 지름길입니다.

2. 5분 빠른 시작

  1. 웹앱 주소를 열고 왼쪽 파일 업로드 영역을 확인합니다.
  2. MusicXML, MXL, musicxml 파일을 업로드합니다.
  3. 중앙 악보가 나타나면 제목, 파트 수, 음표 수가 맞는지 확인합니다.
  4. 왼쪽 도구에서 조옮김, 템포, 음역대 같은 변환을 적용합니다.
  5. 오른쪽 도구에서 코드 분석, 로마 숫자 분석, 주석, 색깔 악보 등을 추가합니다.
  6. 히스토리로 결과를 확인하면서 필요하면 되돌립니다.
  7. 상단 공유, 세션, MXL, PNG, PDF 버튼 중 목적에 맞는 저장 방식을 선택합니다.

3. 파일 업로드와 악보 확인

지원 파일

파일 형식용도
.mxl압축 MusicXML. MuseScore 등에서 내보낸 악보를 보관하기 좋습니다.
.xml, .musicxml일반 MusicXML. 구조 확인과 테스트에 편리합니다.
.mscz로컬 변환 API가 준비된 환경에서 MusicXML로 변환할 수 있습니다.

업로드 절차

  1. 왼쪽 파일 업로드 패널을 엽니다.
  2. 점선 상자에 파일을 끌어다 놓거나 상자를 클릭합니다.
  3. 파일 목록에 이름과 파트/음표 수가 나타나는지 확인합니다.
  4. 중앙 악보가 렌더링되면 다음 작업으로 이동합니다.

히스토리 사용

왼쪽 하단 히스토리는 최근 작업을 순서대로 기록합니다. 실수했을 때 되돌리기 버튼을 누르면 이전 상태로 돌아갑니다. 여러 번 편집한 뒤에도 작업 흐름을 확인할 수 있어 수업 자료를 만들 때 안정적입니다.

4. 왼쪽 변환 도구

왼쪽 도구는 악보 자체를 바꾸는 기능입니다. 조, 음역, 악기, 템포, 레이아웃처럼 결과 악보에 직접 반영되는 작업이 여기에 모여 있습니다.

주요 왼쪽 도구

파일 업로드

MusicXML, MXL, musicxml 파일을 불러옵니다. mscz는 로컬 변환 API가 있을 때 자동 변환할 수 있습니다.

조옮김

특정 조, 12개 장조, 반음 단위, 음정 단위로 악보 전체를 변환합니다.

마디별 조바꿈

곡 중간의 특정 마디부터 조표를 바꾸거나 부분 조바꿈을 적용합니다.

카포

기타 카포 위치에 맞춰 실제 운지와 들리는 음을 조정합니다.

레이아웃 편집

악보 크기, 여백, 줄/페이지 브레이크, 마디 배치를 정리합니다.

음역대 조정

악기 또는 사용자 지정 음역 안에 들어오도록 음을 자동 조정합니다.

이조 악기

클라리넷, 트럼펫 같은 이조 악기용 악보로 변환합니다.

템포 조절

전체 템포를 바꾸고 재생 속도와 표기 템포를 맞춥니다.

마디별 템포

특정 마디에 템포 변화를 넣어 연습 구간을 세밀하게 제어합니다.

Ossia 마디

대체 연주, 쉬운 버전, 변형 구간을 작은 보조 악보로 추가합니다.

음자리표 변환

높은음자리표, 낮은음자리표 등 악보 읽기 목적에 맞게 음자리표를 바꿉니다.

조옮김 팁
단순 반음 이동은 빠르지만 임시표가 복잡해질 수 있습니다. 자연스러운 조표와 이명동음 정리가 필요하면 music21 스마트 조옮김을 사용하세요.

5. 오른쪽 분석/편집 도구

오른쪽 도구는 수업용 해설, 분석, 시각 자료 제작을 돕습니다. 코드, 화성, 주석, 색깔, 운지, 난이도처럼 학생에게 보여 줄 정보를 더하는 기능이 많습니다.

주요 오른쪽 도구

파트 추출

여러 파트 중 필요한 파트만 추출하거나 불필요한 파트를 삭제합니다.

악보 표기 변환

음표 머리, 쉼표, 보표, 기보 요소를 수업 목적에 맞게 바꿉니다.

가사 편집

TXT 가사를 가져오고 음절 단위로 악보에 배정합니다.

이미지/PDF

PNG, SVG, PDF와 텍스트 악보를 생성합니다.

색깔 악보

음, 마디, 역할별 색상으로 학습 포인트를 시각화합니다.

화성 쌓기

선율에 3도/화성음을 추가해 합주 또는 화성 연습 자료를 만듭니다.

코드 도구

코드 기호를 정리하고 불필요한 코드, N.C. 표기를 다룹니다.

숫자 악보

계이름/숫자 기반 학습 악보를 생성하고 원본 가사로 복원합니다.

가사 스타일

가사 글꼴, 크기, 색상을 통일해 읽기 좋은 자료로 다듬습니다.

코드/로마 분석

코드 기호, 로마 숫자, 종지, 조성 흐름을 분석합니다.

운지법/청음

리코더, 칼림바 등 운지 표시와 청음 훈련 활동을 구성합니다.

성부/패턴/형식/난이도/통계

성부 진행, 반복 음형, 곡 형식, 난이도, 음역/음표 통계를 확인합니다.

수업 자료 제작 팁
코드 분석을 먼저 실행한 뒤 주석 메모로 “여기서 딸림화음 확인”, “손가락 바꾸기”, “호흡 위치” 같은 지시를 붙이면 학생용 해설 악보를 빠르게 만들 수 있습니다.

6. 재생과 연습 컨트롤

하단 바는 악보를 소리로 확인하고 연습 구간을 지정하는 공간입니다. 재생, 일시정지, 정지, 현재 마디, 템포, 악기, 볼륨, A-B 반복을 제공합니다.

컨트롤사용 방법활용 예시
재생/정지왼쪽 하단의 재생 버튼을 누릅니다.편집 후 음 높이와 리듬이 맞는지 확인합니다.
템포템포 슬라이더 또는 BPM 값을 조정합니다.느린 연습 버전과 실제 연주 버전을 비교합니다.
악기악기 선택 상자에서 Piano, Strings, Flute 등을 고릅니다.수업 대상 악기에 가까운 음색으로 확인합니다.
A-B 반복A와 B 마디를 지정하고 A-B 버튼을 사용합니다.어려운 마디만 반복 연습합니다.
파트 체크파트 목록에서 재생할 파트를 켜고 끕니다.합주 파트별 연습 자료를 확인합니다.

7. 세션 저장과 URL 공유

작업을 잃지 않으려면 자동 저장, 세션 슬롯, JSON 백업, 공유 URL을 목적에 맞게 함께 사용하세요.

공유 URL 사용 단계

  1. 악보를 하나 업로드하고 필요한 편집을 마칩니다.
  2. 상단 공유 버튼을 누릅니다.
  3. 압축된 URL 또는 QR 코드를 복사합니다.
  4. 받는 사람은 링크를 열면 같은 악보를 불러올 수 있습니다.

세션 메뉴 사용 단계

  1. 상단 세션 버튼을 누릅니다.
  2. 현재 작업을 슬롯에 저장하거나 JSON으로 내보냅니다.
  3. 다른 브라우저나 다른 컴퓨터에서 이어 하려면 JSON 가져오기를 사용합니다.
  4. 브라우저를 닫았다가 다시 열면 자동 저장 복원 배너가 나타날 수 있습니다.
공유 URL 제한
URL 공유는 단일 파일과 비교적 작은 악보에 적합합니다. 편성이 크거나 악보가 매우 길면 PDF, MXL, JSON 세션으로 공유하는 편이 안전합니다.

8. 내보내기

버튼/형식추천 상황주의할 점
MXL다른 악보 편집기에서 다시 열어 수정할 때편집 가능한 원본 보관용으로 가장 좋습니다.
PNG슬라이드, 웹 문서, 문제 이미지에 넣을 때확대 인쇄보다 화면 자료에 적합합니다.
PDF인쇄, 학습지, 학생 배포용 최종본브라우저 팝업 차단이 있으면 새 창이 열리지 않을 수 있습니다.
ABC/LilyPond텍스트 기반 악보 도구와 연동할 때복잡한 악보는 일부 표현이 단순화될 수 있습니다.

9. 자주 쓰는 작업 예시

아래 예시는 실제 수업 준비에서 자주 반복되는 흐름입니다. 각 단계는 메뉴 이름과 화면 위치를 기준으로 작성했습니다.

수업용 조옮김 악보 만들기

  1. 파일 업로드에서 MusicXML을 불러옵니다.
  2. 왼쪽 조옮김 패널을 열고 목표 조를 선택합니다.
  3. 변환 실행을 누른 뒤 중앙 악보가 바뀌었는지 확인합니다.
  4. 오른쪽 이미지/PDF 패널에서 PDF 또는 PNG로 내보냅니다.

학생에게 URL로 악보 공유하기

  1. 악보를 업로드하고 필요한 편집을 마칩니다.
  2. 상단 공유 버튼을 누릅니다.
  3. URL 또는 QR 코드를 복사합니다.
  4. 메신저나 수업 플랫폼에 공유합니다. 큰 악보는 PDF로 내보내는 편이 안정적입니다.

자동 저장된 작업 이어 하기

  1. 브라우저를 다시 열면 이전 세션 복원 배너가 표시됩니다.
  2. 복원하기를 누르면 파일, 히스토리, 편집 상태가 돌아옵니다.
  3. 중요 작업은 세션 메뉴에서 슬롯 저장 또는 JSON 내보내기도 함께 사용합니다.

코드 분석 자료 만들기

  1. 악보를 불러온 뒤 오른쪽 코드 분석 또는 로마 숫자 분석 패널을 엽니다.
  2. 코드 기호 파악 또는 고급 화성 분석을 실행합니다.
  3. 분석 결과가 수업 목적에 맞는지 확인합니다.
  4. 필요하면 주석 메모 패널로 해설을 추가합니다.

10. 문제 해결

상황해결 방법
파일이 열리지 않을 때MusicXML 계열 파일인지 확인하세요. PDF나 이미지 악보는 먼저 MusicXML로 변환해야 합니다.
악보가 보이지 않을 때업로드 직후 잠시 기다리세요. 그래도 비어 있으면 파일 자체가 비어 있거나 XML 구조가 손상되었을 수 있습니다.
공유 URL이 너무 길 때URL 공유는 단일 파일에 적합합니다. 큰 편성 악보나 긴 곡은 PDF/MXL로 내보내서 공유하세요.
PDF가 새 창으로 열리지 않을 때브라우저의 팝업 차단을 해제하고 다시 PDF 내보내기를 실행하세요.
분석 API가 실패할 때music21 기반 고급 분석은 로컬 API 주소가 켜져 있어야 합니다. 기본 기능은 브라우저 안에서 바로 사용할 수 있습니다.
작업을 되돌리고 싶을 때왼쪽 하단 히스토리에서 이전 단계로 돌아갈 수 있습니다. 히스토리는 최근 50개까지 유지됩니다.
권장 작업 습관
큰 편집을 하기 전에는 세션 슬롯 또는 JSON으로 상태를 저장하세요. 완성본 배포 전에는 PDF로 한 번 확인하고, 학생용 링크는 직접 열어 보며 검증하면 좋습니다.

부록. 화면 갤러리

설명서에 사용한 전체 화면 캡처입니다. 메뉴 이름을 찾거나 화면 위치를 다시 확인할 때 참고하세요.

MXL Studio 사용자 설명서

이 설명서는 로컬 앱 화면을 직접 캡처해 제작했습니다. HTML은 브라우저에서 열어 탐색하고, PDF는 인쇄/배포용으로 사용하며, SVG는 전체 흐름을 빠르게 보는 요약본으로 활용하세요.
